# Приложение для анализа банковских операций
 
## Реализован набор функций:

Полный набор реализуемой в приложении функциональности можно разделить на 3 категории:
- ***Веб-страницы***:
  - Главная
  - События
- ***Сервисы***:
  - Выгодные категории повышенного кешбэка
  - Инвесткопилка
  - Простой поиск
  - Поиск по телефонным номерам
  - Поиск переводов физическим лицам
- ***Отчеты***:
  - Траты по категории
  - Траты по дням недели
  - Траты в рабочий/выходной день

### Функция main создающая JSON ответ для страницы главная
### Функция filter_by_date фильтрующая данные по заданной дате
### Функция read_excel читающая .xlsx файл и возвращает список словарей
### Функция greetings функция приветствия
### Функция for_each_card создания информации по каждой карте
### Функция currency_rates запроса курса валют
### Функция top_five_transaction для получения топ-5 транзакций по сумме платежа
### Функция get_price_stock для получения данных об акциях из списка SP500
### Функция simple_search поиска по переданной строке
### Функция log_spending_by_category логирует результат функции в указанный файл
### Функция spending_by_category возвращающая траты за последние 3 месяца по заданной категории
### Функция decorator_spending_by_category логирует результат функции в файл по умолчанию decorator_spending_by_category.json
### Функция decorator_search логирует результат функции в файл по умолчанию decorator_search.json
